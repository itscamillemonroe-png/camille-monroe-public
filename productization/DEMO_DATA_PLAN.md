# Creator Private OS — Synthetic Demo Data Plan

Use a fictional creator brand. Do not imitate a real creator closely enough to create confusion.

Default demo creator:
- Name: Avery Vale
- Handle: @averyvale
- Domain: creator.example
- Membership: $30 / 30 days
- Messaging: 5 credits/message
- Voice calls: 4 credits/minute
- Minimum voice booking: 5 minutes

## Synthetic members
Create 8–12 fictional members with clearly fake/demo names and non-deliverable test emails.

Example statuses:
- pending approval
- approved / unpaid
- active member
- expired member
- blocked member

## Synthetic transactions
Create clearly labeled sample records:
- 3 membership orders
- 3 credit-pack purchases
- 2 tips
- 2 Premium Drop purchases
- 1 refunded/failed example if useful

All demo revenue metrics must say SAMPLE or DEMO DATA.

## Synthetic content
Use:
- generated abstract/lifestyle imagery that is licensed for the demo
- generic posts
- generic creator updates
- fictional Premium Drop thumbnails
- no Camille-owned private media
- no member screenshots
- no real customer conversations

## Synthetic conversations
Create short fictional threads that demonstrate:
- member question
- creator reply
- credit debit
- notification

Do not include sexual or sensitive real-person content in the reusable demo.
